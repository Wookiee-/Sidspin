SidSpin

A Debian sid live ISO that boots into a minimal KDE Plasma session and installs to your disk with Calamares — where you pick the desktop you actually want.

Download ISO Features

Features

A real live desktop you can try before you commit, with a full graphical installer that puts it on your disk.

🖥️

Minimal KDE Plasma

The ISO boots straight into a clean Plasma session: Dolphin, Konsole, Firefox ESR and not much else. Nothing you do in the live session touches your disk.

📦

Calamares installer

Double-click Install SidSpin on the desktop. Partition, create your user, and the installer copies the system to disk with GRUB. The welcome page and desktop chooser are custom-built, not stock.

🎛️

Pick your desktop

The installer asks which desktop you want on the installed machine — KDE Plasma, GNOME, XFCE, MATE, LXQt or Cinnamon — and whether you want it full or minimal. The display manager is set up for you.

🌀

Plymouth spinfinity

Debian's spinning-logo Plymouth theme as the boot splash, in the live image and in the installed system.

🐧

Based on sid — tracks Debian unstable. Built with live-build, installed with Calamares.

🔒

Safe by default — automatic partitioning, LUKS encryption, and nothing is written before you confirm.

🛠️

Bring your own partitions

GParted and KDE Partition Manager are in the live session. Resize a partition or lay out the disk yourself, then point the installer at it.

Desktops

The live image boots into KDE Plasma. During the installation you choose which desktop ends up on your disk.

KDE Plasma default

The live session, and the default on the installed system.

kde-plasma-desktop kwin-x11 sddm

GNOME Desktop

Activities, a large app suite, and GDM3.

task-gnome-desktop gdm3

XFCE Desktop

Lightweight and quick on older hardware, with LightDM.

task-xfce-desktop lightdm

MATE Desktop

A classic layout with modest resource use.

task-mate-desktop lightdm

LXQt Desktop

A very light Qt desktop that starts fast.

task-lxqt-desktop sddm

Cinnamon Desktop

A traditional panel and menu, with LightDM.

task-cinnamon-desktop lightdm

Installation

Write the ISO to USB, boot it, and install from the live desktop.

1. Write to USB

Replace /dev/sdX with your USB device (be careful!):

sudo dd if=sidspin-amd64.iso of=/dev/sdX bs=4M status=progress conv=fdatasync

2. Boot

Boot from the USB. The live session starts and logs you into a minimal KDE Plasma desktop as the user user.

3. Install

Double-click the Install SidSpin icon on the desktop. Calamares walks you through language, keyboard, partitioning and your user account.

4. Choose a desktop

On the Desktop environment page pick the desktop you want — KDE Plasma, GNOME, XFCE, MATE, LXQt or Cinnamon — and whether you want it full (with the usual applications) or minimal (the desktop on its own). It is installed from http://mirror.linux.org.au/debian, so keep the network connected.
